## Top 5 — apply in this order to minimise conflicts

### 1. Add `anthropics/claude-plugins-official` as a marketplace
**Why:** Official Anthropic-curated plugin directory. Becomes your second marketplace alongside ECC.
**How:** In a Claude Code session:
```
/plugin marketplace add anthropics/claude-plugins-official
```
**Cost:** 5 min. Pure config.

---

### 2. Add `wshobson/agents` as a marketplace (upgrade from raw-file source)
**Why:** Already used as a source in `cockpit/curated-catalog.json` (graphics-programmer, unreal-engine-engineer). Repo is now a multi-harness marketplace with 82 plugins / 191 agents / 155 skills / 102 commands. Adopt it as a marketplace, not just a file source.
**How:**
```
/plugin marketplace add wshobson/agents
```
**Cost:** 5 min config + later deprecate raw-GitHub install calls when there's free time.

---

### 3. Install `github/github-mcp-server` (official GitHub MCP)
**Why:** Official MCP. Better auth + rate limits + GitHub API tracking than the community PAT shim currently in use.
**How:** Add to `~/.claude/settings.json` under `mcpServers`:
```json
"github": {
  "type": "stdio",
  "command": "docker",
  "args": ["run", "-i", "--rm", "ghcr.io/github/github-mcp-server"],
  "env": { "GITHUB_PERSONAL_ACCESS_TOKEN": "<your token>" }
}
```
**Cost:** 30 min (token rotation + test). Keep the existing PAT shim as fallback for one release.

---

### 4. Add Excalidraw MCP + Mermaid rendering
**Why:** You asked about diagrams. Excalidraw MCP lets Claude *create* whiteboards; Mermaid renders architecture/sequence diagrams from text. Together they cover "vibe" diagrams and "spec" diagrams.
**How (two parts):**
- Add Excalidraw MCP to `settings.json mcpServers`.
- Inside the Control Center: `npm i mermaid` + create `src/components/projects/DiagramView.tsx` that renders Mermaid blocks from project markdown. Surface it as a 7th project sub-tab.
**Cost:** 1-2 h. Net-new component, no conflict with existing tabs.

---

### 5. Adopt `automazeio/ccpm` (Claude Code Project Management)
**Why:** PRD -> Epic -> GitHub Issues -> parallel agents on worktrees. Exactly the project-orchestration brain `Projects.tsx` lacks. Plugs into GitHub Issues (no new DB).
**How:** Install the marketplace (above) + reference it from per-project workflow. Wire a "PRD -> Epic" button in the project workspace that runs CCPM commands in the embedded terminal.
**Cost:** 3-5 h. Biggest blast radius — touches Projects.tsx, button-prompts, curated-catalog. Save for last.
