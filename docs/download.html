ULTRON Control Center

A local-first cockpit for orchestrating Claude Code, Codex, and Gemini across long, multi-day sessions. Three layers of hierarchical memory, an AI router that picks the right model for the task, and a Plans tab that turns scattered work into something you can actually finish.

Download for Windows All releases

Windows 10 / 11 x64  ·  Self-signed installer (SmartScreen may warn on first run)  ·  v15.2.0

System requirements

OS
Windows 10 or 11, 64-bit. macOS and Linux builds are planned, not shipped yet.
RAM
200 MB idle. Peaks around 600 MB when indexing the vault or running embeddings.
Disk
500 MB for the app, plus whatever your memory vault and Qdrant store grow to.
CPU
Any 64-bit x86 from the last decade. No GPU required.
Network
Only outbound calls you trigger (Claude / Codex / Gemini CLIs). No telemetry.
Required
Claude Code CLI logged into your subscription. Rust, Node 22, and uv if you build from source.

What you get

3-layer memory

L0 hot context, L1 FTS5 brain index, L2 vault notes. Optional Qdrant layer for semantic recall over the same corpus.

AI router

Picks Claude for orchestration, Codex for peer review, Gemini for long context and image work. Never leave the editor.

Plans tab

One source of truth for in-flight work. AI brainstorm, archive on resolve, and Claude-driven execute or review actions.

Skills browser

Navigate your local ~/.claude/skills/ tree plus an archived skill-vault for packs the model should not auto-load.

MCP dashboard

Inspect and toggle Model Context Protocol servers registered in ~/.claude/settings.json. Health checks on demand.

News, schedules, stats

Daily HTML newsletter generator, scheduled tasks surface, and per-session telemetry (tokens, skills, memories, time on task).

Privacy

100 percent local. No telemetry, no analytics, no crash reporters, no outbound network traffic except the calls you trigger through the Claude, Codex, or Gemini CLIs you have already authenticated.

Memory, plans, skills, and indexes live under ~/.ultron/ and ~/.claude/. The optional L3 vault sync is an explicit git push you control.
