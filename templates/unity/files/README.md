# {{name}}

Proyecto de Unity ({{unity_version}}).

## Abrir

Unity Hub → *Add project from disk* → esta carpeta. Si la versión del editor no está
instalada, Unity Hub ofrece instalarla o abrir con otra.

## Estructura

- `Assets/`: escenas, scripts, prefabs y recursos.
- `Packages/manifest.json`: paquetes del proyecto.
- `ProjectSettings/`: ajustes; Unity regenera lo que falte al abrir.
