# v2.5 MCP Audit — Control Center

Auditoría completa de servidores MCP disponibles en el entorno de USER (Windows, `~/.claude/` + `~/.ultron/control-center/`). Objetivo: inventariar todo lo conectado, mapear capacidades, identificar duplicados y proponer integraciones concretas dentro del Control Center 2.x.

> **Notas previas**
> - Las API keys reales en `settings.json` se redactan en este documento.
> - Servidores MCP de `claude.ai` (Figma, Supabase, Vercel, Gmail, Google Calendar/Drive, Notion, Spotify) están conectados vía cuenta web de Claude, no en `settings.json` local — están disponibles en sesión pero no son portables a otros CLIs.
> - El plugin `github@claude-plugins-official` está **disabled** (`false`) en settings. El MCP `github` activo es el HTTP de `api.githubcopilot.com`.

## 3. Quick Wins — Integraciones para el Control Center

Diez integraciones de alto ROI, todas implementables sin tocar arquitectura existente.

1. **Settings → Plugins → "MCP Catalog"**
   Tab nueva que renderiza el JSON de `ecc/mcp-configs/mcp-servers.json` como lista con switches. Toggle = patch atómico a `~/.claude/settings.json::mcpServers`. Salva el copy-paste manual.

2. **Project workspace → botón "Think Hard"**
   Spawnea sesión con prompt prefijado a `sequential-thinking`. Útil para análisis arquitectónico o triage de bugs complejos antes de tocar código.

3. **Cockpit Notifications → Telegram bridge**
   Forward de alertas críticas (build fail, cost critical, hook violations) al chat de Telegram de USER vía `chaindead/telegram-mcp` (ver §4). Reemplaza el `agentPushNotifEnabled` cuando el laptop está cerrado.

4. **Project orchestrator → "Open GH Issue" en cada tarjeta**
   Cuando se despacha una task del kanban, botón directo que invoca `mcp__github__create_issue` con título + descripción de la card y label `cc-dispatched`.

5. **Docs panel → Context7 inline search**
   Barra de búsqueda en cada panel de proyecto que llama `resolve-library-id` + `query-docs`. Resultados pintados en sidepanel. Mata la fricción de saltar a navegador.

6. **Diagnostics → Playwright "Self-test UI"**
   Botón en PC Diagnostic que arranca Playwright contra `http://localhost:1420` (Tauri dev), recorre las 17 tabs, captura screenshots y los persiste en `~/.ultron/diagnostics/<ts>/`. Smoke-test continuo.

7. **Memory tab → Mem0 sync visible**
   El indicador "L3 remote" actual no muestra qué se ha subido. Añadir lista de últimos `add` con timestamps y botón "Search Mem0" que llama al MCP directo. Saca a Mem0 del modo cajón cerrado.

8. **Settings → "Second Opinion" wired al MCP de Codex**
   Hoy `/codex:review` invoca el CLI por subproceso. Si está corriendo el MCP `codex`, redirigir al MCP — más rápido, sin shell. Toggle en Settings.

9. **Agent library tab → Exa search "Find similar agents"**
   En el panel de agentes community, botón que llama `exa.web_search_exa` con el nombre del agente para descubrir variantes/forks publicados después de la última indexación.

10. **Knowledge Graph viewer (nuevo)**
    El MCP `memory` (entity/relation/observation) ya está disponible vía ECC pero no se visualiza. Nueva tab "Knowledge" con grafo D3/cytoscape leyendo `search_nodes` + `open_nodes`. Convierte memory en mapa navegable, no solo store opaco.

## 5. Cleanups (duplicados)

| Duplicado | Recomendación |
|---|---|
| `context7` está 3x (user + ecc + plugin oficial) | Mantener solo el de **user** (versión `@latest`). Desactivar el de plugin oficial (`context7@claude-plugins-official`). El de ECC se carga solo si ECC está activo — OK. |
| `playwright` está 3x (user + ecc + oficial) | Mantener solo el de **user** (apunta a binario local, no descarga npx cada vez). |
| `github` HTTP user + `github` stdio ECC + `github` HTTP plugin oficial (disabled) | Mantener el **user HTTP** (githubcopilot, más rápido). Plugin oficial ya disabled — OK. Stdio ECC útil como fallback offline. |
| `memory` (ECC) vs `mem0` (user) vs `qdrant` (env) | Roles distintos: `memory`=knowledge graph local, `mem0`=L3 cloud, `qdrant`=vector store. **No deduplicar** — son capas L1/L2/L3 distintas. |

**Acción concreta**: en Settings → Plugins, deshabilitar `context7@claude-plugins-official` y `playwright@claude-plugins-official` (ya tienes equivalentes user-level más recientes).
