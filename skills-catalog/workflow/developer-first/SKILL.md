# Developer-First: Framework Expertise

Specialized engineering layer for modern web development stacks.

## Supported Stacks
- **NestJS**: Clean architecture, DI, modules, and DTO validation.
- **React**: Functional components, custom hooks, and state management (Zustand/Redux).
- **Tailwind CSS**: Utility-first styling, design tokens, and layout optimization.

## Core Rules
- **Type Safety**: 100% TypeScript coverage. No `any`.
- **Modularity**: Small, reusable components and services.
- **Performance**: Memoization where necessary, tree-shaking friendly imports.
