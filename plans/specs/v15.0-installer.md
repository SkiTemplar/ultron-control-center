# v15.0 — ULTRON: open-source release + installer

## Objetivo

Permitir que cualquier persona clone el repo `ultron` desde GitHub, ejecute
un único comando, conteste 4-6 preguntas, y tenga el sistema funcional en
su máquina (Windows / macOS / Linux). El usuario elige qué instalar.

**No es** rehacer el sistema. Es preparar **packaging + sanitization +
installer + smoke test** para que ULTRON sea distribuible.

## Scope MVP

```
Phase 0  Branding + LICENSE + README maestro    1-2 h
Phase 1  Sanitizer de paths absolutos           2-3 h
Phase 2  install.ps1 (Windows) + install.sh     3-4 h
Phase 3  Menú interactivo + módulos opcionales  2-3 h
Phase 4  Smoke test post-install                1 h
Phase 5  Release → GitHub + tag v15.0           1 h
```

## Phase 1 — Sanitizer

Hoy el código tiene paths hardcodeados a `C:\Users\USER\...`. Hay que:

```python
# scripts/cockpit/sanitize_for_release.py
- grep -r "C:\\\\Users\\\\USER" → reemplazar por $USERPROFILE / ~
- grep -r "USER" en frontmatter / waivers / config → escrubear
- grep secretos (API keys, OAuth tokens, paths SSH)
- generar reporte de paths sensibles encontrados
```

Tests: `pytest tests/test_sanitize.py` con corpus mock.

## Phase 2 — Installer scripts

```powershell
# install.ps1 (Windows)
[CmdletBinding()]
param(
    [string]$InstallRoot = "$env:USERPROFILE",
    [switch]$Minimal,         # solo cockpit base
    [switch]$Full,            # + 14 personas + MCPs + hooks
    [switch]$NonInteractive,  # CI mode con defaults
    [string]$Profile = "personal"  # personal | team | dev
)
```

```bash
# install.sh (macOS / Linux)
./install.sh --minimal
./install.sh --full
./install.sh --profile=team --install-root=/opt/ultron
```

**Pasos del installer:**
1. Verificar prerequisitos: Python 3.13+, uv, git, node (para MCPs)
2. Clonar `~/.claude/skills/ultron` (o donde se diga)
3. Crear `~/.ultron/` con estructura mínima (cockpit, config, sessions, plans)
4. `uv sync` en el venv del skill
5. Instalar hooks en `~/.claude/settings.json` (con backup del previo)
6. Si `--full`: instalar las 14 personas como skills separadas
7. Smoke test final

## Phase 4 — Smoke test

Tras instalar:

```bash
ultron status                      # OK?
ultron health                      # ≤ 2 warns esperados (news + manifest)
ultron skills manifest status      # 0 errors
ultron plans status                # 0 items (instalación limpia)
```

Si todo pasa → "✅ ULTRON listo. Ejecuta `ultron tui` para arrancar."
Si algo falla → mensaje claro + `~/.ultron/logs/install.log`.

## Acceptance criteria

- [ ] README explica los 3 modos en <2 min de lectura
- [ ] Tests: 100% del scanner sanitizer + 80% del installer (mock fs)

## Riesgos

| Risk | Mitigación |
|---|---|
| Paths hardcodeados que el sanitizer no detecta | Test corpus con todos los formatos: `C:\\Users\\USER`, `~/`, `$env:USERPROFILE`, etc. |
| MCPs piden API keys → onboarding hostil | Installer skip MCPs por default; menú custom marca como opcional |
| Diferencias Windows vs Unix en hooks | Tests CI en GitHub Actions matrix (windows-latest + ubuntu-latest + macos-latest) |
| User instala sobre `~/.ultron` con datos previos | Detección + offer migrate / abort / overwrite |
| Repo público filtra info personal en git history | `git filter-repo` previo al primer push público |
