## Problem

ULTRON tiene 90 subcomandos en `ultron.ps1` (1376 líneas) más una TUI Textual (`tui.py`) que el usuario describe como "diseño bastante pocho". El sistema crece y la fricción de gestionarlo por terminal/comandos memorizables aumenta. Tareas frecuentes (ver status MCP, reintentar conexión, abrir proyecto, ver logs, revisar alertas) requieren memorizar comandos o navegar una TUI con UX limitada.

Además, las notificaciones (v15.0.2) viven en un panel WinForms desacoplado del resto del sistema. No hay punto único donde ver el estado global, los logs históricos, ni gestionar componentes individualmente.

## Non-goals

- **NO** se elimina la CLI (`ultron <cmd>`). La GUI es UN frontend más; los scripts/comandos siguen siendo invocables y son la fuente de verdad de la lógica.
- **NO** se reescriben los scripts PowerShell/Python en Rust. El frontend Tauri llama a los scripts existentes via sidecar/shell-plugin.
- **NO** se hace cross-platform en v15.1. Windows primero. Linux/Mac quedan para v15.X si surge la necesidad.
- **NO** se reemplaza el panel WinForms de v15.0.2 inmediatamente — convive durante la migración hasta que el tray icon Tauri lo absorba.

## Constraints

- Windows 11, sin admin para instalar/correr la app.
- Recursos: idle <50 MB RAM, no impactar gaming (no robar foco, no procesar mientras hay fullscreen exclusive).
- Persistencia: nada se rompe si la app se cierra — scheduled tasks, hooks, MCPs siguen funcionando solos.
- Tray icon obligatorio: la app vive minimizada en bandeja, ventana es opcional.

## Stack — Tauri 2 + React + TypeScript + Tailwind + shadcn/ui

**Por qué Tauri** (vs Electron):
- Bundle ~3 MB vs ~150 MB Electron
- RAM idle ~30-40 MB vs 200-300 MB Electron
- Startup <0.5s vs 1-2s Electron
- Webview nativo Windows (Edge WebView2 ya instalado)
- Sidecar oficial para invocar PowerShell/Python scripts existentes
- Rust en backend = fácil añadir API nativas futuro

**Por qué React + Tailwind + shadcn/ui**:
- Stack maduro, componentes accesibles, dark mode out-of-the-box
- shadcn/ui copia componentes al proyecto (no es dependencia npm, es código tuyo)
- Trabajo visual rápido y modificable

**Por qué TypeScript**:
- Tipado de IPC entre Rust ↔ frontend
- Autocompletado de comandos invoke()

## Fases (entregables independientes)

Cada fase es un commit + entrega visible. Si paramos en cualquier fase, lo entregado funciona aislado.

### Fase 1 — Foundation (1-2 sesiones)
- Crear proyecto Tauri 2 en `~/.ultron/control-center/`
- React + TypeScript + Vite + Tailwind + shadcn/ui scaffold
- Configurar build for Windows (.msi y portable .exe)
- Configurar capabilities/permissions (shell-plugin, notification, tray)
- Tema dark ULTRON (colores del panel WinForms actual)
- Hello-World con tray icon + ventana mínima + invoke() de prueba a `ultron status`
- **Entregable**: app que arranca, vive en tray, muestra ventana al click

### Fase 2 — Dashboard + Notifications integration (1-2 sesiones)
- Widget Dashboard: status global (Qdrant up, MCPs OK, alerts pendientes, próximo backup)
- Tray icon cambia color: verde OK / amarillo warn / rojo critical
- Tooltip resumen al hover
- Centro de notificaciones interno (pestaña Notifications): lee `alerts.jsonl`, agrupa, marca ack
- Notificaciones popup background: cuando la app está cerrada/minimizada y aparece alerta nueva → reusa el panel WinForms (puerta de transición)
- Fullscreen guard heredado de v15.0.2 (yield silencioso ante juegos)
- **Entregable**: si arranca el PC, ULTRON sale a tray, status visible al instante; alertas no invasivas

### Fase 3 — MCPs management (1-2 sesiones)

## Fail-fast order (orden de implementación)

1. Tauri scaffold + ventana vacía con tray → si esto falla, problema de stack
2. Sidecar invocando `ultron status` → si esto falla, problema de IPC con scripts
3. Lectura de `alerts.jsonl` y `mcp-health.json` → si esto falla, problema de filesystem access
4. Tray icon dinámico color por status → core funcional para uso diario
5. Resto de pestañas en orden de la fase

Si Fase 1 fracasa (Tauri no encaja), fallback a Electron mismo plan; si Electron también, fallback a WPF .NET 8.

## Investigación clave (Tauri 2)

- Tray icon docs: `v2.tauri.app/learn/system-tray/` — Rust-side API recommended over JS for cross-platform
- Sidecar: `v2.tauri.app/develop/sidecar/` — `tauri_plugin_shell::ShellExt`, requires capabilities permission
- Comandos Rust → frontend: `#[tauri::command]` macro, automatic JSON serialization
- Bundle size real: ~3 MB ULTRON Control Center proyectado (vs ~150 MB Electron equivalent)
- Webview: Edge WebView2 (Windows 11 ya lo tiene preinstalado)
