### FASE 3 — Reescribir paths en código (45 min · riesgo medio)

**A) `settings.json` — 14 hooks**

Reemplazo masivo:
- `C:/Users/USER/.claude/skills/ultron/.venv/Scripts/python.exe`
  → `C:/Users/USER/.ultron/.venv/Scripts/python.exe`
- `C:/Users/USER/.claude/skills/ultron/hooks/X.py`
  → `C:/Users/USER/.ultron/scripts/hooks/X.py`

**B) `hooks/*.py` — sys.path imports**

Cada hook tiene `sys.path.insert(0, "...scripts/cockpit")`.
Convertir a relativo: `sys.path.insert(0, str(Path(__file__).parent.parent / "cockpit"))`.

**C) `SKILL.md` workspace table**

```
Antes:
  Skills      C:\Users\USER\.claude\skills\ultron\
  Memoria     C:\Users\USER\.ultron\

Después:
  Skill def   C:\Users\USER\.claude\skills\ultron\        (markdown only)
  Code        C:\Users\USER\.ultron\scripts\
  Memoria     C:\Users\USER\.ultron\
  Tests       C:\Users\USER\.ultron\tests\
```

**D) `protocols.md`, `references/*.md`** — grep por paths hardcoded y actualizar.

**E) `cockpit_base.py`** — `ULTRON_SKILL_ROOT` constante necesita re-evaluación. SKILL.md sigue en `.claude/`, así que la helper `read_ultron_version()` queda igual.
