Proposito: Generador web de prompts JSON y imágenes para prendas de e-commerce usando Stable Diffusion XL
  - Aplicación web para generar automáticamente prompts JSON optimizados y fotografías profesionales de prendas de ropa para catálogos e-commerce, usando Stable Diffusion XL con parámetros técnicos consistentes.
  - Backend Express.js (Node.js) con dos variantes: server.js genera prompts JSON localmente sin API externa, server-replicate.js integra Replicate para generación real de imágenes (SDXL). Frontend vanilla JS con CSS moderno (grid, animations, glassmorphism).
  - Master JSON implementa 6 secciones profesionales: Subject (prenda: categoría, tipo, color, material lana peinada, talla M, planchado), Composition (maniquí invisible, frontal, moderado negativo, centrado), Background (neutro profesional #f5f5f5, degradado suave, sombras), Lighting (difuso estudio, 5500K, 1:1.5 key:fill), Camera (50mm focal, f/8, ISO 100, nivel ojos), Consistency (seed 300321, sRGB, 4:5 aspect, 3000x2400px, 80px safety borders).
  - Frontend captura 3 inputs de usuario (categoría, tipo/detalle, color), envía POST a /api/generate, recibe JSON estructurado, lo muestra, permite copiar prompt, descargar JSON, o guardar localmente con /api/save-local.
  - Actualmente server.js genera solo prompts JSON sin llamar a APIs de imagen. Alternativa server-replicate.js disponible pero requiere API token de Replicate. Documentación de troubleshooting en SOLUCION_API.md: Replicate preferido, Hugging Face como alternativa, local AUTOMATIC1111 como opción offline.
  - Raíz contiene servidores (server.js, server-replicate.js), carpeta 'public/' alberga interfaz web (index.html, app.js, styles.css), package.json define dependencias, archivos .md documenten APIs e instalación.
  - npm: express 5.1, @huggingface/inference 4.11.3, replicate 1.3.0, cors, body-parser, dotenv. API keys: REPLICATE_API_TOKEN (preferido, más estable) o HF_API_KEY (Hugging Face alternativa).
  - Inference steps 50, guidance_scale 7.5, scheduler K_EULER, refine expert_ensemble_refiner, seed fijo 300321, resoluciones 768x1024 a 1280x1024, output PNG. Brand safety: negative prompts previenen logos, marcas, textos, etiquetas.
