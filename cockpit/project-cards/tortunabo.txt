Proposito: Third-person cooperative racing game for 1–4 players controlling anthropomorphic turtles across procedurally generated level chunks, with networking via Steam Sockets.
  - Tortunabo is a cooperative 1–4 player third-person racing game in UE5.6 using Steam Sockets for online multiplayer, with player-controlled anthropomorphic turtles navigating procedurally-generated chunks to reach the finish line.
  - Server-authoritative design using Unreal's replication system (Replicated variables, RPCs) with GameInstance persisting across level transitions and seamless travel between Menu/Lobby/Run phases.
  - ATortugaCharacter combines third-person camera (SpringArm + FOV interpolation), Enhanced Input, stamina/dive mechanics, inventory (2-slot), knockdown/ragdoll, procedural leg/arm/head animation, emotes (wheel-based), and VOIP proximity component.
  - Server-only chunk spawner that maintains a FIFO buffer of 5 ahead + 1 behind, selecting chunks from Easy/Medium/Hard pools based on PassedChunkCount thresholds or custom difficulty sequence, with InSocket/OutSocket alignment for seamless chain.
  - TN_RunGameMode orchestrates race: countdown → in-progress race with DBNO bleedout timers → results screen with scoreboard → seamless travel back to Lobby. Scoring: RankScore (podium 400/300/200/100/50) + ScorePickups + TimeBonus.
  - Project is in final stages (T-Day defense delivery). Core systems implemented: multiplayer networking (Steam), chunk generation, DBNO/revive, cosmetics, procedural animation, emotes, VOIP. README documents setup and configuration validation steps.
  - ATN_InteractableBase and subclasses (Pickups, Directs) provide common interface (CanInteract/Interact). World contains ~39 gameplay actor types: enemies (Crab, Seagull, Jellyfish), obstacles (BananaPeel, BreakablePlatform), collectibles (ScorePickup, ConchPickup, RescuePickup), hazards (DeathZone, SlowZone, StormVolume), mechanics (Totem, UmbrellaInteractable, ButtonInteractable, PressurePlate).
  - TN_CoopPlayerState replicates per-player flow state and cosmetics (helmet/skin). UTN_CosmeticSaveGame persists unlockedHelmets, equippedHelmet, equippedSkin, and accumulatedScore to disk.
