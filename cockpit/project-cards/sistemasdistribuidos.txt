Proposito: Distributed systems coursework: multi-client TCP chat, broker-based FileManager with service discovery, load balancing, keep-alive mechanisms, containerization with Docker, and Kubernetes orchestration.
  - Six major deliverables progressing from basic TCP chat (Entrega1-2) through distributed FileManager with broker (P1fileManager) to containerized Kubernetes deployment (P2FileManager), plus Lambda serverless computing for calculator with RDS.
  - Three-tier system: Broker (port 1066) mediates service discovery and load balancing; multiple Servers (port 1067) register and maintain heartbeat; Clients query broker for least-loaded server, then connect directly to assigned server for persistent session.
  - Pack/unpack template functions in utils.h serialize C++ types to byte buffers; every message starts with type enum, followed by parameters in fixed order; sendMSG/recvMSG wrap TCP with 4-byte size prefix.
  - One thread per connection (server listening spawns thread per accept, broker spawns thread per client message). Shared data structures (serversMutex protects servidoresRegistrados map) use lock_guard<mutex> for thread safety.
  - Client-side FileManager (distributedFileManager.cpp) overloads constructor to query broker, connect to assigned server, and forward method calls as RPC messages; server-side FileManager instances instantiated per client and map to serialized responses.
  - Three progressively complex scenarios: basic (no volumes, stateless), advanced-hostpath (local node storage, pods share within node), advanced-nfs (shared NFS across all pods/nodes with PersistentVolume+PersistentVolumeClaim).
  - Server sends ACK_BROKER keep-alive to broker every 5 seconds; broker monitor thread increments keepAliveCounter for each server; if counter exceeds KEEP_ALIVE_MAX_COUNT (2), marks server alive=false to prevent new client assignment.
  - All K8s YAMLs require apiVersion, kind, metadata, spec. Deployment selector.matchLabels must match template.metadata.labels. Service selector targets pods. ContainerPort ↔ targetPort must align. PV/PVC storageClassName must match.
