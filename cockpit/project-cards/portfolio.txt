Ficha de "portfolio" (JavaScript (JSX)) recordada de la memoria (stale-by-default: verifica contra el codigo actual):
Proposito: Página web personal minimalista en blanco y negro que exhibe proyectos web y videojuegos usando React + Vite.
  - React 19.2 + Vite 7.2 como frontend bundle, con ESLint para QA y diseño minimalista en blanco y negro.
  - /src contiene componentes React en /components, datos de proyectos en /data, estilos globales en /styles; entrypoint es main.jsx→App.jsx.
  - Paleta reducida (blanco #fff, gris #f5f5f5 alt, negro #000 accent) con variables CSS y escala de spacing uniforme (xs-xl).
  - 7 componentes presentacionales (Header, Hero, About, Projects, Games, Contact, Footer) + ProjectCard genérico; ninguno usa useState, useEffect, context o custom hooks.
  - Los proyectos web y juegos se definen como arrays de objetos en /data/projects.js, consumidos por componentes Projects y Games que mapean ProjectCard genericamente.
  - Página de una sola columna: Header fijo → Hero → About → Projects (web) → Games → Contact → Footer, cada sección con id para nav anchors.
  - README contiene guía paso a paso para pushear a GitHub y desplegar en Vercel; Vite auto-detectado como buildtool.
  - index.html con <div id='root'> + <script type='module' src='/src/main.jsx'> renderiza App con React.StrictMode.
